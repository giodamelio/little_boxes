## [1.13.0] - 2026-11-21

### Added

- Add --border-color and --color to colour the box border

### Fixed

- Measure box width without counting ANSI escape codes
- Expand tabs to spaces so the right border lines up
- Stop open colours and hyperlinks leaking onto the border
- Exit quietly when stdout is closed early
- Print errors to stderr instead of stdout
- Reject a title that spans more than one line
